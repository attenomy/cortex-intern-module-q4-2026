# AGENTS.md : Attenomy Cortex Operating Principles

Welcome to **Attenomy Cortex**. All AI coding assistants, agents, and contributors operating in this repository must strictly adhere to the following principles.

---

## 1. Zero Hallucination & Fact-Based Delivery
- Never fabricate model metrics, accuracy statistics, or benchmark results.
- Ground all latency assertions in reproducible profiling tools (e.g. Locust, cProfile, PyTorch profiler).
- When in doubt, verify active code in `api/` or ask for technical clarification.

---

## 2. Attenomy Architecture & Product Standards
- **Core Role**: Enterprise Autonomous Multi-Agent Orchestration & Cognitive Knowledge Retrieval Engine.
- **Latency Budget**: Query intent routing must execute with p95 < 50ms.
- **Design Conventions**:
  - Squircle button geometry (`rounded-2xl` / 16px).
  - Deep obsidian dark palette (`#09090b`, `#121217`) with emerald (`#10b981`) and violet (`#6366f1`) accents.
  - No empty buzzwords: speak objectively about inference latency, embeddings, token caches, and schema validators.
